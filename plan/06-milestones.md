# 6 · Milestones

## M1 — working demo ✅ done

- [x] Scaffold Vite + React + TS (strict), one `app.css`, vitest.
- [x] `types.ts` + `catalog.ts` + `filter.ts` (pure logic, unit-tested — 15 tests).
- [x] `data/architectures.json` + `data/sets/m6502.json` (56 mnemonics, 151 documented opcodes), generated by `npm run build:data` from `scripts/m6502-opcodes.txt`.
- [x] Pickers (arch → variant), search box, table with expandable rows, counts, empty state, sorting.
- [x] Invariant tests asserting counts, opcode uniqueness, mode/byte agreement, no `B` flag, and the externally-verified cycle penalties — 23 tests.
- [x] Sort by mnemonic or category, and `/` focuses the search box (both pulled forward from M2 — a few lines each).
- **Verified:** `npm run dev` shows the 6502 set; searching `lda`, `bit 6` (⇒ `BIT`), `carry`, `($nn),Y` each return correct rows; expanding any row shows its mode table with all opcodes and cycles.

## M2 — polish ✅ done

- [x] URL state (architecture/variant/search) so rows are shareable — `?arch=&variant=&q=`, written with `replaceState` so filtering does not fill the back button. Ids from the URL are resolved against the catalog, not trusted.
- [x] Sticky mnemonic column when the table scrolls sideways (the header row was already sticky) — CSS only.
- [x] Copy-to-clipboard of an expanded row (markdown), with a legacy `execCommand` fallback for insecure origins and sandboxed frames, and a visible `Copy blocked` state when both paths fail.

- **Verified:** `?q=bit+6` restores the filter on load; typing writes `?q=%28%24nn%29%2CY`; copy fills the clipboard on a real click; the mnemonic column stays pinned at `scrollLeft` max on a 375px viewport.
- Skipped: `sort` is deliberately not in the URL — it is a viewing preference, not part of what a link is sharing. Add it if that turns out to be wrong.
