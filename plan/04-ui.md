# 4 · UI spec

## Layout (single screen)

```
┌──────────────────────────────────────────────────────────┐
│  cpuinstr — instruction set browser        56 · 151  ◐    │  header + counts
├──────────────────────────────────────────────────────────┤
│  Architecture [MOS 6502 ▾]   Variant [6502 (1975) ▾]     │  pickers
├──────────────────────────────────────────────────────────┤
│  [ 🔍 filter mnemonic, description or operands…   ]       │  search
├──────────────────────────────────────────────────────────┤
│  LDA ▸  Load a byte into A · 8 modes · N,Z               │  collapsed row
│   ┌────────────────────────────────────────────────────┐ │
│   │ A9 LDA #<imm8> 2B 2c │ A5 LDA <zp> 2B 3c │ …       │ │  expanded:
│   │ full description …  examples …                     │ │  mode table
│   └────────────────────────────────────────────────────┘ │
│  LDX ▸  Load a byte into the X index register · 5 modes  │
└──────────────────────────────────────────────────────────┘
```

## Behavior

- **Pickers** — variant options depend on the selected architecture; first valid pair is preselected. Changing either clears the search box.
- **Search** — one box; case-insensitive substring match against `mnemonic` + `aliases` + `summary` + `description` + every `modes[].operand`/`name`/`opcode`. Empty query ⇒ all rows.
- **Table** — columns: Mnemonic (mono, bold) · Summary · Modes (count) · Opcode bytes (all, compact — `LDA` is `A9 A5 B5 AD BD B9 A1 B1`) · Bytes · Cycles · Flags · ▸ expand.
- **Expanded row** — full description, examples, then the per-mode table from [03-data-model.md](./03-data-model.md) (mode name, operand syntax, opcode, bytes, cycles).
- **Sorting** — mnemonic A→Z by default; toggle to category then mnemonic.
- **Header counts** — show `mnemonics · opcodes` and, while filtering, the *matched* pair (`3 of 56`).
- **Empty state** — “No matches for `xyz`” + a clear-search button.
- **Flags column** — only flags the instruction changes, e.g. `N,Z` for `LDA`. `B` never appears (see [03-data-model.md](./03-data-model.md)); the `NV-BDIZC` layout string is shown once in a header legend, not per row.
- **Accessibility** — native `<select>`s and `<input>`; expand-toggle is a real `<button>` with `aria-expanded`; table is a semantic `<table>`.

## Look

- System font stack; `ui-monospace` for mnemonics/opcodes; light theme by default.
- One `app.css`, small BEM-ish class names; no CSS framework.
- Dark theme: listed under [06-milestones.md](./06-milestones.md) (M3, optional).
